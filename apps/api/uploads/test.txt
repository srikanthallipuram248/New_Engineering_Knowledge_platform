1. What GTUBE actually is?

GTUBE stands for Generic Test for Unsolicited Bulk Email.
It is a standard spam test string used to verify whether a spam filter is working correctly (similar to how EICAR is used for antivirus testing).

If a mail system detects GTUBE content, it should flag the email as spam.
